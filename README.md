# Арбитражный сканер → Telegram

Ищет связки между биржами и шлёт готовый сигнал. Сам не торгует.

- 🔁 **Перевод**: купить на A → вывести сетью X → продать на B. Чистый % по стакану под твой объём, с комиссиями и выводом.
- ⚖️ **Хедж**: спот → фьючерс и фьючерс → фьючерс, без перевода.

## Запуск на Railway

1. Создай бота у @BotFather, возьми токен.
2. Залей `main.py`, `requirements.txt`, `Procfile` в новый репозиторий GitHub.
3. Railway → New Project → Deploy from GitHub.
4. В Settings выбери регион **Europe или Singapore** (с американских IP Bybit и часть бирж не отвечают).
5. Variables: `TELEGRAM_BOT_TOKEN`. Задеплой, напиши боту `/start` — он пришлёт chat id.
6. Добавь `TELEGRAM_CHAT_ID`, перезапусти. Придёт «Сканер запущен» со статусом.

## Команды

`/status` · `/min 1.5` · `/hedge 1.5` · `/size 500` · `/pause` · `/resume`
(изменения из команд сбрасываются при перезапуске — постоянные значения задавай в Variables)

## Переменные

| Переменная | По умолчанию | Что это |
|---|---|---|
| `SIZE_USDT` | 500 | объём одной связки |
| `MIN_NET_PCT` | 1.0 | мин. чистый % для перевода |
| `MIN_HEDGE_PCT` | 1.0 | мин. чистый % для хеджа |
| `EXCHANGES` | bybit,okx,gate,kucoin,mexc,bitget,htx,bingx | список бирж (id из ccxt) |
| `MIN_VOLUME_USDT` | 100000 | мин. оборот 24ч |
| `MAX_SPREAD_PCT` | 20 | выше — отсекаем как подозрительное |
| `SCAN_INTERVAL_SEC` | 30 | частота скана |
| `COOLDOWN_MIN` | 30 | не повторять ту же связку |
| `BLACKLIST` | OPENAI,ANTHROPIC | монеты через запятую (по умолчанию pre-IPO перпы) |
| `MAX_NEG_FUNDING_PCT` | 0.1 | хедж: макс. фандинг против позиции за период |
| `ALLOW_UNVERIFIED` | 0 | 1 = слать связки с непроверенной сетью |
| `ENABLE_TRANSFER` / `ENABLE_HEDGE` | 1 | включить/выключить тип сигналов |

## Статус сетей и ключи

Открыт ли вывод/депозит, бот узнаёт у биржи. Часть бирж отдаёт это только с API-ключом.
В `/status` строка «Сети проверяются» покажет, по каким биржам данные есть.
Для остальных можно добавить ключ **только на чтение** (без торговли и вывода):
`BYBIT_API_KEY`, `BYBIT_SECRET`, `OKX_API_KEY`, `OKX_SECRET`, `OKX_PASSWORD` и т.д.
Без ключа биржа всё равно участвует в хедж-сигналах.

## Что бот НЕ проверяет

- Совпадает ли контракт монеты (бывают разные монеты с одним тикером).
- Время перевода и число подтверждений.
- Лимиты вывода и минимальные суммы.
Перед входом это надо смотреть руками.
